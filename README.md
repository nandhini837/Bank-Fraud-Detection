# Bank Fraud Detection System

## Project Description

Bank Fraud Detection System is an AI and Machine Learning based
web application that predicts whether a credit card transaction
is fraudulent or not.

The system provides fraud probability, risk level and
SHAP-based explanations for the prediction.

## Features

- Fraud transaction detection
- Fraud probability
- Risk level
- SHAP-based explanation
- Transaction history
- Dashboard
- Normal transaction sample
- Fraud transaction sample
- Clear transaction history
- FastAPI backend
- Responsive web interface

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI
- Uvicorn

### Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Logistic Regression
- SHAP

## Dataset

Credit Card Fraud Detection dataset.

The dataset contains:

- Time
- V1 to V28
- Amount
- Class

Class 0 = Normal transaction

Class 1 = Fraudulent transaction
